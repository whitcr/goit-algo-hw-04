Timsort був найшвидшим на всіх тестованих наборах даних

Сортування злиттям показало продуктивність, значно кращу за вставки, особливо на більших масивах, але поступилося Timsort.

Сортування вставками було найповільнішим, особливо на великих обсягах даних

Timsort поєднує кращі риси обох методів і оптимізований для реальних даних
